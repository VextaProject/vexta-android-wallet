# Vexta Wallet for Android

Official open-source Android wallet for the Vexta (VTX) blockchain.

## Features

- Create and restore a 12-word recovery phrase
- Multiple deterministic receiving addresses
- Native SegWit Vexta addresses
- Verified SPV block headers
- BIP158 compact-filter scanning
- Local transaction history
- Send and receive VTX
- QR-code scanning
- Encrypted recovery phrase storage
- Signed in-app updates with SHA256 verification

## Requirements

- Android 8.0 or newer
- Android SDK 36
- Java 17

## Build

Run: ./gradlew assembleDebug

Debug APK: app/build/outputs/apk/debug/app-debug.apk
